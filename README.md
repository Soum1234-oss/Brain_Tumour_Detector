# Brain_Tumour_Detector

This project applies **noise reduction filters** (Adaptive Median + Weighted Mean) on MRI brain images and evaluates them using **MSE** and **PSNR** metrics.

##  Features
- Applies adaptive median filtering
- Applies weighted mean filtering
- Evaluates results with MSE & PSNR
- Saves results to CSV
